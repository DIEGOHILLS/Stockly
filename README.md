# 📦 Stockly – Full‑Stack Product Store (PERN Stack)

---

**Stockly** is a PERN stack product store demonstrating full‑stack CRUD operations, REST APIs, PostgreSQL integration, and production deployment.

---

## 🛠 Technical Skills Demonstrated

* Full‑stack development (PERN)
* REST API design & CRUD operations
* PostgreSQL relational database design
* Express.js middleware & routing
* Client‑server architecture
* State management with Zustand
* Environment configuration (.env)
* Rate limiting & basic security
* Deployment & CI‑ready setup

---

## ✨ Core Features

* Create, read, update, and delete products
* Responsive UI with Tailwind CSS & DaisyUI
* Global state management
* Centralized server & client error handling
* Light/Dark theme toggle
* Deployed full‑stack application

---

## 🧩 System Architecture

```
React Frontend
   ↓
Express REST API
   ↓
PostgreSQL Database
```
